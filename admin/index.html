Payment Currencies by Country

Students in a listed country are charged in that local currency, with the payment options shown, instead of USD. Options are a comma-separated list of Flutterwave payment methods (e.g. "card, mobilemoney, ussd, banktransfer") -- Flutterwave automatically hides any option that doesn't apply to the customer's currency, so it's safe to list more than you're sure of.

Referral Withdrawal Auto-Hold Rules

Referral withdrawals settle instantly by default -- no admin click needed. A request is held for manual review instead only when one of these trips. Regardless of the outcome, any withdrawal (instant-paid or held) can still be pulled back with Reset on the Withdrawals tab.
